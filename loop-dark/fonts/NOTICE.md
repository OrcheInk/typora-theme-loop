# 字体来源与许可

本目录下的 `FiraCodeNerdFontMono-*.woff2` 是子集化后的字体文件。

| 项 | 内容 |
| --- | --- |
| 字体家族 | FiraCode Nerd Font Mono |
| 上游 | Nerd Fonts 的 FiraCode 补丁版（FiraCode Nerd Font） |
| 基础字体 | Fira Code，© The Fira Code Project Authors（https://github.com/tonsky/FiraCode） |
| 许可 | SIL Open Font License, Version 1.1（见 `FiraCode-OFL.txt`） |
| 本仓库的改动 | 使用 fontTools 子集化，只保留拉丁/希腊/西里尔/符号区，去掉 Nerd Fonts 图标字形；保留 `calt` 连字与 `ss01`–`ss10` 风格集 |
| 保留字重 | Regular 400、Bold 700 |

按 OFL 1.1 的要求：字体可以随本主题一并分发，但必须附带上述许可证与版权声明，且不得将修改后的字体作为独立字体产品单独发售。本仓库只把它作为主题的附属资源使用。
